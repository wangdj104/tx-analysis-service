## 角色、权限与状态

| 角色 | 必要权限及边界 |
| --- | --- |
| 记录所有者 | 有效账号／角色及本人拥有的有效患者记录，可读取及记录已发布事项 |
| 分配医生 | 当前有效医生角色及有效患者分配，临床权来自该分配 |
| 家属 | 当前家属角色及明确有效 `CARE_PLAN` 授权；`READ` 读取，`WRITE`／`PROXY` 另可记录 |
| 护理 | 当前有效护理角色、未过期有效分配及明确 `CARE_PLAN` 授权；记录需 `WRITE`／`PROXY` |
| 管理员 | 管理护理分配；角色不赋予临床读取／发布／复核捷径，不替代所有者同意 |

家庭成员身份及旧空白／全模块授权不会自动加入 `CARE_PLAN`。行动项分配不是访问授权。引用还需原 `MEASUREMENTS`／`MEDICAL` 模块当前权限，受限时只显示存在关联记录。撤权也影响历史及已成功命令重放。

计划状态为 `DRAFT`、`ACTIVE`、`COMPLETED`、`CANCELLED`；行动状态为 `OPEN`、`NEEDS_HELP`、`SUBMITTED`、`CONFIRMED`、`SUPERSEDED`、`CANCELLED`。未完成／求助逾期与已提交待复核分开显示。`CONFIRMED` 表示已复核记录，不证明临床改善；首次／最新提交及当前待复核起始时间分别保留。
