## 已实现的实际路径

原有照护旅程测量与血压／血糖自测仍分库存储。随访模式保存返回持久身份回执，再独立核验当前权限并读取判定、修订及随访链接。个人随访依次记录负责人接手、处理、本人／协助反馈及所有者有原因关闭；临床升级开启新一轮，最终关闭必须由当前指派医生完成。

护士必须同时有当前护理指派与明确 `MEASUREMENTS` 授权；指派不会自动授权，也不会附带 `CARE_PLAN` 或临床关闭权。管理员身份不等于临床权限。更正／作废保留原始快照、原因与历史，开启新的复核周期，旧接手／处理／反馈不能直接作为新一轮完成依据。正常复测不会自动关闭事项。

现有照护中心、照护旅程、自测、预警、医生及护士工作台已有按权限呈现的入口。超时复用原请求，换患者、退出、迟到响应与权限撤销有独立处理。通知的渠道接收、患者阅读、接手、处理、复核与健康改善是不同事实；未知投递不自动重试。

当前判定 API 缺少权威比较单位，因此界面暂不显示归一化比较值及阈值数值。原始读数／单位、判定、策略、背景及各阈值名称仍保留。没有修改原有临床阈值或单位换算政策。
