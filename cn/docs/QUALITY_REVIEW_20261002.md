## 核心流程分段合成稳定性观察

探针执行英文病历、问诊与医生工作台的实际 Vue 脚本及 Vue 响应式逻辑，使用原生计时器，包括 1,800 ms 消息轮询与 6,000 ms 列表轮询。API、OCR/压缩、FileReader、DOM、媒体及其他平台接口由合成适配器提供。每轮重建组件，因此覆盖反复操作与生命周期，并非单个浏览器会话始终挂载。

- 第一段：**02:51:23.645–03:02:50.376 UTC**，完成 17 轮，含未完成轮次共执行 1,062 次断言，实测 **686.731 秒**。第 18 轮因原生 6,250 ms 定时器略早返回而触发测试驱动的计时断言并停止。此前产品检查已通过；该未完成轮次的失败快照仍有一个存活 Vue 作用域，随后进程退出
- 原失败证据已保留。测试驱动改为基于单调时钟截止时间的条件等待；产品代码与轮询间隔未改变
- 第二段为 **03:04:30.051–11:15:00.001 UTC**，两段间隔 **99.675 秒**。实测 **29,429.950 秒（8 小时 10 分 29.950 秒）**，完成 736 轮 / 44,896 次断言，产品和测试驱动均零失败，无段内观察中断记录。两段监测源码哈希一致

核心两段合计 **753 个完成轮次、45,958 次断言（包含未完成轮次），产品零失败、测试驱动单独失败一次**。累计实测 **30,116.681 秒（8 小时 21 分 56.681 秒）**，不含 99.675 秒间隔。753 个已完成轮次边界上的受跟踪计时器、待处理适配请求、Vue 作用域与预览 URL 均为零。

第二段 RSS 从 57,225,216 增至 72,458,240 字节，已用堆从 10,905,888 增至 19,777,264 字节；采样峰值分别为 72,843,264 与 19,808,936 字节。最终受跟踪清理计数为零。这里如实记录内存变化，不据此诊断产品泄漏或保证没有泄漏。

中断属于本次结果的一部分。已完成轮次的资源检查不能支持“所有时刻零资源”或“无内存泄漏”的笼统结论，两段运行也不能表述为十小时不间断稳定性测试。
